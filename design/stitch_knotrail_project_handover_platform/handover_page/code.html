Important Architectural Decisions (ADRs)

3 Landmark Decisions Verified

Historical trade-offs agreed during sprint cycles, preserving exact context, rationale, and underlying commit diffs.

ADR-041: Migration from Go Worker to Rust Ingestion Daemon Accepted
Date: April 14, 2025

Rationale: Go GC pauses at 60k EPS caused sporadic p99 spikes exceeding 450ms. Re-architecting with zero-allocation Tokio streams in Rust locked p99 jitter down to 34ms while reducing compute instances by 40%.

commit Commit #8a1f9c0 (Rust Runtime PR #302) • Deciders: E. Rostova, M. Vance, D. Klein
ADR-038: Dual-write Fallback via Redis Cluster During Kafka Partition Rebalance Accepted
Date: Feb 22, 2025

Rationale: During dynamic cluster rebalances, producer buffers breached memory limits. A temporary ephemeral write-buffer to local Redis nodes prevents client 503 drops.

fact_check Evidence Specs #SPEC-084-REDIS • Deciders: E. Rostova, S. Chen
ADR-035: Envelope Encryption Using Customer-Managed AWS KMS Keys Accepted
Date: Jan 11, 2025

Rationale: SOC2 and ISO27001 requirements mandated per-tenant isolation of payload encryption keys prior to resting on S3 cold storage.

security Security Review SEC-TITAN-09 • Deciders: SecOps Audit Board
